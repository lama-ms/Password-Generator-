# Random Password Generator

A customizable password generator built using HTML, CSS, and JavaScript. The application allows users to generate random passwords, adjust their length, choose whether to include numbers and symbols, and switch between light and dark themes.

## Features

- **Random Password Generation:** Generates two passwords at a time.
- **Customizable Length:** Supports password lengths from 4 to 22 characters.
- **Character Options:** Independent toggles for including numbers and symbols, with uppercase and lowercase letters available by default.
- **Light and Dark Mode:** Switches between two visual themes.
- **Copy to Clipboard:** Allows users to copy either generated password with one click.
- **Copy Feedback:** Changes the copy icon after a password is copied.
- **Input Validation:** Displays an error message for password lengths outside the supported range.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works

1. Enter a password length between 4 and 22.
2. Choose whether to include numbers and symbols.
3. Click **Generate passwords** to generate two random passwords.
4. Click the copy icon to copy a password to the clipboard.
5. Use the theme button to switch between light and dark modes.

The application uses JavaScript's `Math.random()` to select characters based on the selected options.
